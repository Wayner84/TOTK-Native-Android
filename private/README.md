# Private local inputs

This directory is intentionally excluded from Git except for this notice.

Do not copy original game containers into the repository. Keep owner-supplied inputs and all derived material in a separate private location, or in ignored subdirectories under `private/` when a local tool requires it.

Keys, tickets, certificates, saves, proprietary binaries, extracted assets, hashes tied to private files and generated game-derived code must never be pushed, attached to issues, included in CI artifacts or distributed in releases.
