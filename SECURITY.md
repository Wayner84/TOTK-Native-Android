# Security policy

## Reporting

Please report memory-safety issues, unsafe mapping/protection transitions, path traversal, integer overflow, cleanup failures or accidental proprietary-data exposure through a private GitHub security advisory rather than a public issue.

Do not include ROMs, keys, game binaries, extracted assets or game-derived generated material in a report. Use synthetic fixtures and sanitized descriptions.

## Supported state

Only the current `main` branch is supported. This is experimental research software and does not provide a playable game, production security guarantee or warranty.
